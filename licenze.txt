Inside this same package you will find the following programs that can be useful for you (you will find them in the folder “Tools” located in the folder “Software”):
-	Flowlight: this is a program used to make some basic configurations (change the IP of the controller and give an address to the light modules) and to test the system, as it allows to connect to the controller and send (and receive) messages to the controller without having to encapsulate them in TCP/IP frames. 
-	Reflexer: This is a simulator of our pick to light system. You can connect to reflexer as if it was a real controller and it will reply and react exactly as the real thing. In other words, you will be able to test how our system works right now without needing to actually have the physical material. Also, in the future, this simulator will also allow you to simulate your whole installation (so that you don’t need to wait until the real installation is finished to test that your software works as expected).

-	Lightstep: This is a dll you can use to simplify the communication with our controllers in case your program is based on C# or Visual Basic. Of course, if your program is based on other programming languages (or simply prefer to do so), you can also communicate perfectly with our controllers, you will only need to program the exchange of the commands via TCP/IP protocol (most of our clients do this).

-	PTL Tester: This is a small program that allows you to generate easily the message to activate the modules (specially the PP5 command). It can also be used to connect directly to the controller and send those commands to test them.
